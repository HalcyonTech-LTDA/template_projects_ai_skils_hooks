# Hardware

Referências de hardware: datasheets, app notes, design guides.

Fichas transversais (normas IPC, capacidades da JLC, importacao, `kicad-cli`) ficam em
`docs_projeto/referencias/`, secao "Eletronica e PCB". Aqui ficam os datasheets e app notes
especificos deste produto, com link e a secao que sustentou cada decisao.

> Template. Ao duplicar para um novo projeto, substituir pelo conteúdo real desta pasta.
