# Prototipagem

Revisões de protótipo (Rev_A, Rev_B, Rev_C…): notas de bring-up, achados e mudanças entre revisões.

Uma pasta por revisao (`Rev_A`, `Rev_B`...). A nota `<placa>_Rev<R>_Bring_Up.md` e criada por
`novo_projeto.py --docs` (skill `pcb-projeto`): inspecao, energizacao trilho a trilho com fonte
limitada, teste por bloco e a lista numerada de defeitos que abre a revisao seguinte.

> Template. Ao duplicar para um novo projeto, substituir pelo conteúdo real desta pasta.
