# Simulacoes

Simulações eletrônicas (SPICE, EMC, térmica): inputs, outputs e relatórios.

Use o modelo `Simulacao_Template`. O KiCad 10 tem simulador SPICE (ngspice) integrado ao
esquematico; a familia `pcb-*` nao automatiza simulacao — registre aqui o circuito simulado,
os modelos usados e o resultado que sustenta a escolha de componente.

> Template. Ao duplicar para um novo projeto, substituir pelo conteúdo real desta pasta.
